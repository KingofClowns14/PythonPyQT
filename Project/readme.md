# Кулинарная книга и калькулятор калорий

Десктопное приложение на Python и PyQt6 для ведения личного каталога кулинарных рецептов и автоматизированного расчета суммарной калорийности блюд на основе их компонентного состава (ингредиентов).

Пункт 1. Техническое задание (ТЗ) и реализованный функционал

Приложение разработано в соответствии со следующими техническими требованиями:

- Каталог рецептов:
- Просмотр списка сохраненных блюд с указанием их итоговой калорийности.
- Быстрый поиск по названию с подтверждением и защитой от пустой выдачи.
- Детальный просмотр карточки блюда (название, фотография, калорийность, полный перечень ингредиентов).

- Калькулятор калорий и управление составом:
- Автоматический расчет калорийности в реальном времени по формуле: `(вес / 100) * калорийность_на_100г`.
- Блокировка ручного ввода итоговых калорий — значение формируется строго на основе таблицы состава.
- Возможность добавления и удаления строк ингредиентов.

- Работа с базой данных (SQLite):
- Использование двух связанных таблиц (`recipes` и `ingredients`) с внешним ключом `FOREIGN KEY` и каскадным удалением `ON DELETE CASCADE`.
- Реализация полного цикла операций CRUD: чтение (`SELECT`), создание (`INSERT`), изменение (`UPDATE`), удаление (`DELETE`).

- Валидация и безопасность ввода:
- Кастомные делегаты `NumericDelegate` и `IngredientNameDelegate` для ограничения ввода на уровне виджетов: запрет ввода букв и отрицательных значений в числовые поля, блокировка спецсимволов в названиях.
- Комплексная проверка данных при сохранении с выводом единого списка всех обнаруженных ошибок.

- Интерфейс и мультимедиа:
- 3 формы, спроектированные в QtDesigner (`.ui` файлы).
- Поддержка изображений блюд (`QPixmap`) с сохранением пропорций и алгоритмом сглаживания.
- Звуковое сопровождение (`QSoundEffect`): зацикленная фоновая музыка ожидания, звуки сохранения и удаления.

Пункт 2. Стек технологий

- Язык программирования: Python 3.10+
- Графический фреймворк: PyQt6 (версии 6.6.0 и выше)
- Дизайнер интерфейса: QtDesigner / PyQt6-tools
- СУБД: SQLite3 (встроенный драйвер Python)
- Сборщик standalone-версии:\*\* PyInstaller (версии 6.4.0 и выше)

Пункт 4. Установка и запуск из исходного кода

Шаг 1. Клонирование репозитория

- git clone https://github.com/KingofClowns14/PythonPyQT.git
- cd Project

Шаг 2. Установка зависимостей

- pip install --upgrade pip
- pip install -r requirements.txt

Шаг 3. Запуск программы

python main.py

Шаг 4. Инструкция по сборке исполняемого файла (.exe)

- 1.  Для сборки автономной версии без зависимостей от окружения Python используется
      модуль PyInstaller.

          - Перекомпиляция интерфейсов из XML (при необходимости)
          - Если в .ui файлы вносились изменения через QtDesigner, необходимо перегенерировать Python-модули:
          - python -m PyQt6.uic.pyuic -x ui/main.window.ui -o ui/ui_main.py
          - python -m PyQt6.uic.pyuic -x ui/add_recpie.ui -o ui/ui_add.py
          - python -m PyQt6.uic.pyuic -x ui/view_recipe.ui -o ui/ui_view.py

- 2. Подготовка точки входа
  - В файле main.py необходимо убедиться, что активен импорт класса для автономной
    версии:
  - from ui_windows_exe import MainWindow

- 3. Компиляция через PyInstaller
  - Выполните команду в терминале:
  - py -m PyInstaller --noconsole --onefile main.py
  - Флаги: - --noconsole — отключает системное окно командной строки Windows при работе
    GUI. - --onefile — собирает все исполняемые модули и зависимости в один файл
    main.exe.

Пункт 5. Комплектация Standalone-версии

После завершения процесса в папке dist/ появится файл main.exe. Для корректной
работы приложения скопируйте рядом с ним:

1.  Папку assets/ со всеми медиафайлами.
2.  Файл базы данных recipes.db (при его отсутствии файл будет инициализирован
    автоматически).

Итоговый состав автономной директории:

- dist/
  - assets/
    - * add.wav
    - * delete.wav
    - * wait.wav
    - * default_food.png
    - * recipes.db
    - * main.exe

Пункт 6. Руководство пользователя (Управление)

- Мышь:
  - Одиночный клик левой кнопкой мыши (ЛКМ) — выбор рецепта в списке.
  - Двойной клик ЛКМ — открытие детального окна просмотра выбранного блюда.
  - Клик правой кнопкой мыши (ПКМ) по рецепту — вызов контекстного меню с
    пунктами «Редактировать блюдо» и «Удалить блюдо».

- Клавиатура:
  - Delete — удаление выбранного блюда (с диалогом подтверждения).
  - Ctrl + F — быстрый вызов строки поиска блюда.
  - Escape — сброс поискового фильтра и возврат к полному списку.

- Калькулятор калорий:
  - Кнопка + Добавить ингредиент добавляет строку в таблицу состава.
  - Кнопка - Удалить ингредиент удаляет выбранную строку.
  - Редактирование веса или калорийности автоматически обновляет итоговую
    сумму в поле «Калории».
